# Gurú Café — demo de la web

Web estática de una sola página (HTML, CSS y JavaScript simple, sin frameworks) para Gurú Café, Calle 13 N.º 4478, Berisso Centro.

**Es una demo privada.** Usa la marca y las imágenes de @gurucafe.ar sin permiso todavía, así que:
- Lleva `noindex` y `robots.txt` para que Google no la indexe.
- La carpeta `fotos/` está en el repositorio (decisión de Simon, 2026-10-29) para publicar con GitHub Pages. Salen de capturas del Instagram de Gurú y de fotos de licencia desconocida: reemplazarlas antes de la web definitiva.
- Horarios, formas de pago, WhatsApp y carta son de **EJEMPLO**: buscar `EJEMPLO` en `index.html` y reemplazar antes de mostrarla al dueño.

Ver el sitio: abrir `index.html` en el navegador.

Demo publicada: https://simonfabrizio.github.io/Guru-Cafe/
